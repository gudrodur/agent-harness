# Launchers

Terminal remote control: opens a titled tab running the agent with its brief, confirms it started on screen, and refuses to close a window it did not launch. The opencode launcher hands the brief over as `--prompt` and proves the start from opencode's own session row, which names the model. The Claude Code launcher passes the brief as the initial prompt, can turn Remote Control on, and proves the start from the session's own transcript; with `--resume` it reopens an existing session and proves it from the rows written after the launch, and `claude-resume-set.sh` snapshots the live sessions before a reboot and replays them after.

Files: `bin/opencode-tab.sh`, `bin/claude-tab.sh`, `bin/claude-resume-set.sh`, `lib/tab-ledger.sh`

`claude-tab.sh --retire <window-id>` closes a window the launcher did not start, on the strength of a handover row that `agent-send --claim-role R --take-over` left (see `docs/seat-roles.md`); `--seat --role R --reseat <window-id>` opens the replacement seat whose first prompt does the takeover and the retire, and the launcher proves both from the store. The caller's identity is `CLAUDE_CODE_SESSION_ID`, or `--as <session>`, which is self-asserted: `--as` is an escape hatch that can impersonate a taker, and the guards that remain are the row, the pid, the session in the window and idleness. `claude-tab.sh --close <window-id> --after-loka` closes a window the launcher did not start when its seat reported "loka done" after its session began and is idle now; it refuses a busy seat, the caller's own window and a seat with no such report. Exit codes: `docs/exit-codes.md`.
